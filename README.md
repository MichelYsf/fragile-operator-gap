# The Fragile-Operator Gap: Assumption‑Extraction Protocol and Coded Taxonomy

This repository contains artefacts for the paper **"The Fragile‑Operator Gap: A Stack‑Layered Audit of Implicit Operating‑Environment Assumptions in Modern Cybersecurity Frameworks"**. The aim of this project is to document the five‑step assumption‑extraction protocol, publish the coded 49‑cell taxonomy derived from four widely used security frameworks, and provide supplementary materials that facilitate open replicability.

## Contents

- **protocol/five_step_protocol.md** – A detailed description of the five‑step assumption‑extraction protocol used to identify implicit operating‑environment assumptions.
- **taxonomy/49_cells.csv** – A 49‑cell matrix of counts summarising how many assumptions were mapped to each combination of stack layer (seven layers) and environmental dimension (seven dimensions).
- **corpus/sources.bib** – A list of bibliographic references to the frameworks analysed and other primary sources used in the study.
- **CITATION.cff** – Citation metadata for citing this repository.
